## 发布注意事项（通用）

1. **必须标注非官方**：所有文案都带 "fan-made / unofficial / 玩家自制"。不要出现 "official countdown"，避免商标与误导投诉。
2. **不要承诺时间不会变**：统一用 "based on current reports / 如有官方调整会同步更新"。
3. **平台链接策略**：
   - YouTube/Twitter/Facebook/Discord 可直接贴链接；
   - B站评论区大概率被吞，链接放主页简介或置顶评论；
   - Reddit 先读版规，选允许工具分享的板块或 weekly thread，首帖语气求反馈不求点击。
4. **投放节奏**：11/12 预载日一波（蹭"pre-load"搜索）、11/18 新西兰解锁时一波（蹭"already playing"热度）、11/19 发售当天主冲。距发售越近，"what time does GTA 6 come out" 搜索量越高。
5. **英文站是默认首页**，英文平台引流直接给根域；中文平台给 `/gta6-countdown`，别发反。
